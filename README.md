🌦️ Weather Prediction Website

A responsive web application that provides real-time weather updates and future forecasts for any city using weather APIs. The site is designed to be simple, fast, and mobile-friendly with interactive features for better user experience.

🚀 Features

Search weather by city name

Display current weather (temperature, humidity, wind speed, pressure)

21-day weather forecast

Interactive charts for historical weather trends

Fully responsive design (works on desktop & mobile)
